## 🏗️ Technical Overview: Arduino

Arduino is an open-source electronics platform based on easy-to-use hardware and software. It's the brain behind most of the robotics projects found in this repository.

### Pros & Cons

| Feature | Pros | Cons |
| :--- | :--- | :--- |
| **Accessibility** | Low barrier to entry for beginners and hobbyists. | Limited processing power compared to SBCs like Raspberry Pi. |
| **Community** | Massive global library support and troubleshooting resources. | Lack of built-in complex OS (No native multitasking). |
| **I/O Capability** | Robust Analog and Digital pins for diverse sensor integration. | Limited onboard memory (SRAM) for large data processing. |
| **Cost** | Extremely affordable for prototyping and simple automation. | Higher power consumption compared to bare microcontrollers. |

## 🚀 Getting Started

### Prerequisites
* [Arduino IDE](https://www.arduino.cc/en/software) for `.ino` files.
* A C++ compiler (like GCC) or IDE (VS Code, CodeBlocks) for `.cpp` files.

### How to use
1.  **For C++ Exercises:** Compile any `.cpp` file to see the logic in action.
2.  **For Arduino Projects:** Open the desired folder, load the `.ino` into your IDE, and upload to your board.
